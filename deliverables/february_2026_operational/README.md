# Февраль 2026: операционный прогноз

56 запусков для T1/T2; 2688 строк прогнозов на 48 часов и 1344 строки неперекрывающегося февраля (первые 24 часа каждого запуска). Начало расчётов — 31 января, 23:00 Asia/Almaty. Мощность нормализована [0,1]. Февральской фактической мощности нет, поэтому метрики точности не рассчитаны.

В комплект входят отчёт, выходные CSV, точные входные CSV, две модели и 28 погодных квитанций с URL, диапазонами байтов, Last-Modified и SHA-256 исходных объектов. При упаковке проверены все даты, хеши входов, модели и воспроизводимость числовых прогнозов из входных CSV. Версии среды указаны в bundle_manifest.json.

**Исходные GRIB и погодный кеш не включены.** Отчёт сохраняет ссылки и сведения о погодных выпусках. Полное воспроизведение от источника погоды требует сети и повторной загрузки операционного архива ECMWF. Контрольные суммы пакета подтверждают целостность файлов, а не служат независимым доказательством исторической публикации.

Используйте доверенную копию проекта и совместимые версии зависимостей. Пакет содержит pickle обученных моделей; загружайте только доверенные артефакты.

```sh
ARTIFACT_DIR=<bundle>/artifacts python -m scripts.fetch_operational_weather
ARTIFACT_DIR=<bundle>/artifacts python -m scripts.replay --weather-source operational --output-dir <bundle>/reproduced
```

Сравните reproduced/forecast.csv и reproduced/daily_forecast.csv с файлами этого комплекта. Загрузка архива проверяет время публикации копий относительно момента расчёта; это не утверждение о точном времени первой публикации. Никакого автоматического перехода к фактической погоде или условным данным нет.

Источник: ECMWF Open Data, https://www.ecmwf.int/en/forecasts/datasets/open-data . Условия распространения: CC BY 4.0, https://creativecommons.org/licenses/by/4.0/ .

## Проверки готового комплекта

- `audit.json`: 289 проверок покрытия, хронологии и целостности — все прошли.
- `data_inventory.json`: исходные файлы заканчиваются 31 января; дополнительная папка не содержит февральского факта.
- `weather_fetch_report.json`: 28 из 28 выпусков, без ошибок.
- `reproduction_check.json`: модели перенесены в другой каталог, входные CSV созданы заново; оба итоговых CSV совпали побайтно. Исходный GRIB-кеш общий и перепроверен.
- `verification.json`: проверка API, браузера, чата и целевые тесты; платных LLM-проверок не было.

Все 56 расчётов выполнены на замороженных моделях. Нативные прогнозы погоды получены из операционного архива ECMWF; фактическая погода февраля не подставлялась.
