# Первая локальная версия модели

Цель: быстро обучить отдельные модели T1/T2 на MacBook, сохранить воспроизводимые артефакты и проверить загрузку/инференс. Пользователь разрешил параллельную работу быстрых агентов. UI, HTTP, архив погоды и LLM в эту задачу не входят.

## Параллельные задачи

| Исполнитель | Файлы | Результат |
|---|---|---|
| Главный агент | contracts.py, scripts/train.py, зависимости, README | Окружение, общий CLI, январская диагностика, финальный запуск и проверка |
| Агент данных | data.py, tests/test_data.py | Два проверенных источника, UTC, полные почасовые наблюдения, аудит |
| Агент модели | model.py, tests/test_model.py | Регрессор каждой турбины, cutoff, сохранение/загрузка, границы инференса |
| Агент проверки | scripts/smoke_model.py | Независимая проверка двух турбин × двух origin × 24/48 часов |

## Порядок

1. Поднять `.venv`, установить только библиотеки для данных, регрессии и тестов; скопировать неизменённые CSV из Downloads в игнорируемый `data/`.
2. Одновременно реализовать согласованные интерфейсы ingestion/model/smoke.
3. Собрать общий CLI. Для каждой турбины выполнить отдельную январскую диагностику на измеренной погоде: train строго до января, проверка на завершённых январских часах. Не называть её точностью реального погодного прогноза.
4. Обучить финальные модели на полных часах с концом не позднее `2026-01-31T18:00:00Z`. Сохранить модель, метаданные и хэши.
5. Выполнить граничные тесты и восемь синтетических сценариев инференса, записать фактические команды/результаты в README.

## Фиксированные решения

- `HistGradientBoostingRegressor(max_iter=100, max_leaf_nodes=15, random_state=42)` на `[wind_speed_ms, temperature_c]` отдельно для T1/T2; CPU, без поиска гиперпараметров.
- Только шесть различных десятиминутных интервалов образуют обучающий час. Нулевые мощности сохраняются; пропуски меток не заполняются.
- Время исходников временно трактуется как начало интервала в `Asia/Almaty`; неоднозначное/несуществующее время исключается с аудитом.
- Результат — нормализованная мощность `[0,1]`. Февральской истины нет; погодные входы smoke-теста синтетические.
- Этот план описывает действия текущего запуска; подтверждённый итог и ограничения записываются в README.
