# Задачи команды: февральский прогноз ВЭС

Основной сценарий готов: Samal → турбина и день февраля → операционный архив
ECMWF → точный CSV → замороженная модель → график, таблица, анализ и чат.
Текущий прогноз сохранён отдельно. Предыдущий запрет февральского UI отменён.

## Дальнейшая работа после демо

Это ограничения данных и оценка качества, а не недописанные P0-модули.

| Ответственный | Задача | Критерий завершения |
|---|---|---|
| B + владелец данных | Получить фактическую мощность февраля | Отдельные честные MAE/RMSE для T1/T2 и горизонтов; без подмешивания факта в входы |
| A/B + владелец данных | Уточнить SCADA: интервалы, часовой пояс и нормировку | Подтверждённое описание измерений и обновлённый аудит |
| B | Оценить влияние операционной сетки 0,25° относительно Open-Meteo обучения | Хронологическая проверка на сопоставимых прогнозных выпусках |
| C | Репетиция произвольного диалога с настроенным LLM | Ответы согласованы с численными таблицами; дополнительные платные проверки только по разрешению |

не менять; условный старый комплект не переименовывать в verified.
