# Задачи команды: демо прогноза мощности ВЭС

## Согласованный сценарий

Основной режим: турбина → день февраля 2026 → 24/48 часов → конкретный архивный
выпуск погоды → CSV → замороженная модель → график, таблица и анализ → чат.
Live остаётся отдельным режимом. Последний запрос пользователя отменяет прежний
запрет на февральский интерфейс. [Результат и ограничения](docs/february-replay.md).
